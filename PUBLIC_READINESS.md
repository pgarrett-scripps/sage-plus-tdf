# Public launch readiness

Prepared on 2026-09-26. This is a release preparation record, not authorization to publish. The GitHub repository remains private and the real package manifest retains `publish = false`.

## Publication boundary

No public repository, registry upload, public documentation deployment or package-name reservation was performed. A package name appearing available does not reserve it. Existing private release tags and assets remain unchanged.

The final launch requires an explicit decision to make the repository public and publish the package. After that decision, follow `RELEASING.md`, verify the intended crates.io account and its email, enable its narrowly scoped publishing credential, recheck name availability and rerun the release checks. Never commit credentials. The registry performs server-side checks that a local dry run cannot prove.

## Bruker scope

The intended registry name is `timsrust-reader`. The package is a focused TDF frame reader, not a compatible substitute for upstream spectrum synthesis. Turso remains pinned to a prerelease and unsupported calibration models return errors.

Small historical acquisition fixtures came from the retained upstream TimsRust history. New SQLite and compressed-frame regression files are synthetic fixtures. The calibration reference JSON records values generated by Sage Plus against the public tdfpy v2.2.0 DDA, DIA and PRM fixtures. All three `analysis.tdf` hashes were independently checked against that public tag. Sage and tdfpy MIT notices are retained alongside the upstream notices. No vendor SDK binary is distributed by this reader.

Reference input location: [tdfpy v2.2.0 test data](https://github.com/tacular-omics/tdfpy/tree/v2.2.0/tests/data).

The raw-frame qualification report contains hashes and counts from four acquisitions. It does not certify equivalence of synthesized spectra, broaden calibration support or include those acquisitions for redistribution.
